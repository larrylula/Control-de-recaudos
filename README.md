# Control Recaudos Android

Prototipo funcional nativo para Android.

Incluye:
- Registro de cliente, valor y medio de pago.
- Total de recaudos del día.
- Listado de recaudos.
- Cierre de caja con cálculo de faltante/sobrante.

## Abrir
1. Descomprime el proyecto.
2. Ábrelo con Android Studio.
3. Espera la sincronización de Gradle.
4. Ejecuta en un teléfono o emulador Android.

Es una primera versión; los datos todavía viven en memoria y se pierden al cerrar la app.
